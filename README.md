# 🧠 AdaLoad-JMeter 

**AdaLoad-JMeter** presents an intelligent  workload controller for Apache JMeter that is machine learning based.

---

## 🚀 Core Features
- 📊 Dynamically adjusts load during test execution
- ⚙️ Automatically increases, holds, or decreases request rate
- 🎯 Removes dependence on fixed preconfigured thread/throughput settings
- 🧠 Enables continuous adaptation based on system behavior
- ⚖️ Uses an in-plugin Logistic Regression model
- 🚀 Predicts next-window SLO violation risk
- 🔁 Operates without external ML services or APIs
